How this version works

  1. The GitHub Pages PWA handles the interface and file selection.
  2. A Python service uses pdfplumber to detect the PDF's ruled/grid tables.
  3. English tables are retained; page-break continuation rows are merged.
  4. openpyxl creates and formats the Excel workbook.

Important: GitHub Pages cannot run Python. Therefore Version 3 uses GitHub Pages for the PWA and a separate Python API for accurate table extraction.
