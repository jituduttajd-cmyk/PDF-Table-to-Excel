How it works

  1. Select a text-based PDF containing tables.
  2. PDF text and coordinates are read locally in your browser.
  3. Table rows/columns are reconstructed and English headers are filtered.
  4. A formatted .xlsx file is generated and downloaded.

Important: This browser implementation is designed for text-based PDFs. Scanned/image-only PDFs need OCR. Your original Python program uses pdfplumber's table detector; a browser does not expose that same detector, so this version reconstructs tables from PDF text positions.

PDF.js + ExcelJSPDFs are processed locally.
